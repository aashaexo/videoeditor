# videoeditor

Video editing skills for Devin.

## Skills

- `skills/editing-paper-explainer-videos`: turns a talking-head clip into a calm vertical explainer. Warm grid background, green 3D cards, typing text, dotted links, stacked serif captions on face shots. Face-first, with graphics only for key ideas.

## Requirements

- ffmpeg (with libass), Python 3
- `pip install faster-whisper numpy playwright && python3 -m playwright install chromium`
- Fonts in `~/.fonts`: Fraunces, Lora, Inter (from github.com/google/fonts)

See `SKILL.md` for the workflow.
